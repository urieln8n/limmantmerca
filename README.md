# Limmant Merca

Web de Limmant Merca, limpieza industrial del grupo Diagonal Merca (Mercabarna). Contacto comercial: Elkin Darío Piedrahita.

- HTML estático en `public/`, sin build.
- Cloudflare Workers: build command vacío, deploy command `npx wrangler deploy`.
- Dominio: elkindario.andresrendon.com

Pendiente del cliente: WhatsApp de Elkin (constante `WA` en `public/index.html`), foto del equipo (`data-slot="equipo"`), logo original en vector.
